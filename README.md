1. Open a terminal in the root folder.
2. In the terminal, run this code: `npm run dev`.
3. Start in Google on the local host.
4. If you get an error, type `dir` in the terminal.
5. Add the following to the terminal: `cd .\gods-eye-view-main`.
6. And run `npm run dev`.
